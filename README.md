# Tabletke 🌸

Cute aplikacija za beleženje jemanja tablet. Vse se shrani lokalno v brskalniku (`localStorage`) — brez backenda, brez baze.

## Funkcije
- Označi, ali si danes vzela tableto (ali še ne)
- Mesečni koledar z zgodovino
- Niz dni in skupno število
- Cute roza tema z živalskimi stickerji
- Deluje na telefonu in računalniku

## Hostanje na GitHub Pages

1. Naredi nov repozitorij na GitHubu (npr. `tabletke`).
2. V tej mapi:
   ```
   git init
   git add .
   git commit -m "Tabletke 🌸"
   git branch -M main
   git remote add origin https://github.com/<TVOJE-UPORABNISKO-IME>/tabletke.git
   git push -u origin main
   ```
3. Na GitHubu pojdi v **Settings → Pages**.
4. Pod **Source** izberi `Deploy from a branch`, branch `main`, folder `/ (root)`. Shrani.
5. Čez minuto bo aplikacija na `https://<TVOJE-UPORABNISKO-IME>.github.io/tabletke/`.

Pošlji ji link, naj ga doda na začetni zaslon telefona (Safari/Chrome → Share → Add to Home Screen) in bo zgledalo kot prava aplikacija.
